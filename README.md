# Mi Ciudadanía 🇺🇸

**Guía interactiva en español para el proceso de naturalización a ciudadano estadounidense**

## Descripción

Mi Ciudadanía es una aplicación web que guía a residentes permanentes a través del proceso de naturalización estadounidense de manera interactiva y en español.

## Funcionalidades

- Guía paso a paso del proceso N-400
- Preguntas de práctica para el examen cívico
- Simulación de entrevista
- Disclaimer legal completo (13 cláusulas)

## Instalación

```bash
npm install
npm run dev
```

## Tecnologías

- React 18
- Vite 5
- JavaScript (ES Modules)

Esta aplicación es únicamente para fines informativos y educativos. No constituye asesoramiento legal. Consulte con un abogado de inmigración calificado para orientación específica a su caso.
